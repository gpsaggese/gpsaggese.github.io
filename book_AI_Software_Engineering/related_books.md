## Rating Scales

- **Technical**: Yes if it is a technical book, otherwise No
- **Goodreads (1-10)**: Goodreads rating x 2
- **Reviews (1-10)**: relative volume of reviews (10 = 1500+, 1 = fewer than 10)
- **Academic (1-10)**: theoretical depth and scientific rigor
- **Practical (1-10)**: industry applicability and hands-on utility
- **Clarity (1-10)**: accessibility and pedagogical quality
- **Average**: simple mean of the previous six values
- Use `n/a` for a value that cannot be found, and skip it in the average

## Cluster 1. AI-Assisted Coding and Agentic Development

### Augmented Software Design: Taming the Genie

- **ID**: B001
- **Authors**: Kent Beck
- **Year**: 2027 (forthcoming)
- **Publisher**: O'Reilly Media
- **Technical**: Yes
- **Scores (1-10)**: Goodreads n/a, Reviews 1, Academic 4, Practical 7, Clarity 8,
  Average 5.0
- **Content**:
  - From the creator of Extreme Programming and pioneer of Test-Driven Development
  - Builds on:
    - His "Tidy First?" series
    - His writing on "augmented coding"
  - Looks at keeping software design healthy when AI agents write much of the code
  - Pre-order only
    - Retailers list release dates between January and March 2027

### Beyond Vibe Coding: From Coder to AI-Era Developer

- **ID**: B005
- **Authors**: Addy Osmani
- **Year**: 2025
- **Publisher**: O'Reilly Media
- **Technical**: Yes
- **Scores (1-10)**: Goodreads 6.6, Reviews 4, Academic 4, Practical 8, Clarity 7,
  Average 5.9
- **Content**:
  - Practical guide for experienced developers that works with any AI coding tool
  - Contrasts quick, prompt-driven "vibe coding" with a more disciplined "AI-assisted
    engineering" process
  - Focuses on the last ~30% of the work that AI still handles poorly
    - Architecture
    - Edge cases
    - Review
  - Covers:
    - Prompting
    - Prototyping
    - End-to-end web app workflows
    - Multi-agent coding systems
  - Dedicated chapters on:
    - Security
    - Maintainability
    - Reliability
    - Ethics of AI-generated code

### Vibe Coding: Building Production-Grade Software with GenAI, Chat, Agents, and Beyond

- **ID**: B007
- **Authors**: Gene Kim, Steve Yegge
- **Year**: 2025
- **Publisher**: IT Revolution
- **Technical**: Yes
- **Scores (1-10)**: Goodreads 7.5, Reviews 7, Academic 4, Practical 6, Clarity 7,
  Average 6.3
- **Content**:
  - Treats AI-assisted coding as a real engineering discipline, not a shortcut
  - Draws on:
    - Yegge's decades at Google and Amazon
    - Kim's DevOps research
  - Full of real stories about failures with AI coding and how to reduce those risks
  - Introduces the "FAAFO" framework:
    - Faster
    - Ambitious
    - Autonomous
    - Fun
    - Optionality
  - Strong on organizational and leadership implications
    - Good for tech leads and CTOs
  - Winner of a 2026 Axiom Book Awards Gold Medal

### AI-Assisted Programming: Better Planning, Coding, Testing, and Deployment

- **ID**: B008
- **Authors**: Tom Taulli
- **Year**: 2024
- **Publisher**: O'Reilly Media
- **Link**: https://www.oreilly.com/library/view/ai-assisted-programming/9781098164553/
- **Technical**: Yes
- **Scores (1-10)**: Goodreads 6.5, Reviews 4, Academic 3, Practical 6, Clarity 7,
  Average 5.3
- **Lessons**: 01
- **Relevance**: Planning-to-deployment workflows across ChatGPT, Claude, Copilot,
  and Cursor, and a modular prompting methodology for AI-generated code
- **Content**:
  - Entry-level guide to using AI tools across the software development lifecycle
    - Requirements
    - Planning
    - Coding
    - Debugging
    - Testing
    - Deployment
  - Explains how the technology works:
    - Large language models
    - The transformer model
    - How to evaluate AI coding tools
  - Covers prompt engineering
  - Surveys the tools:
    - GitHub Copilot, the leading tool
    - Alternatives such as CodeWhisperer, Tabnine, Cursor, and Code Llama
  - Shows AI help with tedious tasks
    - Regular expressions
    - Starter code
    - Object-oriented classes
    - GitHub Actions
  - Written before the rise of agentic coding tools
    - Tool coverage is dated
  - Mixed Goodreads reviews (3.27 from 51 ratings)
    - Readers call it a fine intro but written in a rush
