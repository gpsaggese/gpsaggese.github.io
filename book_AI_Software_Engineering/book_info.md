## Beyond Vibe Coding: From Coder to AI-Era Developer
**Authors:** Addy Osmani
**Year:** 2025 (O'Reilly)

- Practical guide for experienced developers that works with any AI coding tool
- Contrasts quick, prompt-driven "vibe coding" with a more disciplined "AI-assisted engineering" process
- Focuses on the last ~30% of the work (architecture, edge cases, review) that AI still handles poorly
- Covers prompting, prototyping, end-to-end web app workflows, and multi-agent coding systems
- Dedicated chapters on security, maintainability, reliability, and ethics of AI-generated code

## Vibe Coding: Building Production-Grade Software With GenAI, Chat, Agents, and Beyond
**Authors:** Gene Kim, Steve Yegge
**Year:** 2025 (IT Revolution)

- Treats AI-assisted coding as a real engineering discipline, not a shortcut
- Draws on Yegge's decades at Google and Amazon and Kim's DevOps research
- Full of real stories about failures with AI coding and how to reduce those risks
- Introduces the "FAAFO" framework: faster, ambitious, autonomous, fun, optionality
- Strong on organizational and leadership implications; good for tech leads and CTOs
- Winner of a 2026 Axiom Book Awards Gold Medal

## Spec-Driven Development
**Authors:** Simon Martinelli
**Year:** Not confirmed (Apress)

- Short pocket guide to writing specifications before handing work to a coding agent
- Explains why clear specs produce more reliable agent output than ad-hoc prompting
- Surveys the current tooling that supports spec-first workflows

## The Claude Code Operating Model
**Authors:** Jia Huang
**Year:** Not confirmed (Packt)

- About running Claude Code across a team, not just for one developer
- Covers security, cost control, and team adoption
- Good follow-on to an individual-focused Claude Code book

## Agentic Coding with OpenAI Codex CLI
**Authors:** Daniel Vaughan
**Year:** Not confirmed (Packt)

- In-depth (~670 pages) guide to OpenAI's Codex CLI agent
- Fills a gap: the tool has little coverage outside official docs
- Best for teams that work mainly with OpenAI tools

## AI Engineering: Building Applications with Foundation Models
**Authors:** Chip Huyen
**Year:** 2025 (O'Reilly)

- About building AI *into* products rather than using AI to write code
- Covers evaluation, RAG, agents, fine-tuning, latency, cost, and reliability
- Widely regarded as the top book for software engineers moving into AI engineering
- Dense and technical; assumes you already write code and use APIs

## Augmented Software Design: Taming the Genie
**Authors:** Kent Beck
**Year:** Forthcoming (early 2027, O'Reilly)

- From the creator of Extreme Programming and pioneer of Test-Driven Development
- Builds on his "Tidy First?" series and his writing on "augmented coding"
- Looks at keeping software design healthy when AI agents write much of the code
- Pre-order only; retailers list release dates between January and March 2027
