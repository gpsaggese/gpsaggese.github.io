# Small Research Projects

- The project is _"Research a question"_:
  - Implement a research project based on the instructions
  - Create Jupyter notebooks to demo your project
  - Commit code to GitHub and contribute to an open-source repo
  - Write a blog entry or paper for your project
  - Present your project in a video
- You can pick a new project or continue a research idea that other students already
  started
  - It is important to learn how to build on top of other people's work
    - Only about 1% of the time you get to start something completely new on the job
    - About 99% of the time you take something built by somebody else and improve it
      or add to it
- Resources:
  - [Research page](https://github.com/gpsaggese/gpsaggese.github.io/tree/master/research)
  - [Research ideas](https://github.com/gpsaggese/gpsaggese.github.io/tree/master/research/ideas)
  - [Research summary](https://github.com/gpsaggese/gpsaggese.github.io/blob/master/research/ideas/README.md)

## How to Pick a Project

1. The projects available are the ones not marked `DONE` in the project description
   list:
   - [DATA605 projects](https://github.com/gpsaggese/gpsaggese.github.io/blob/master/class_project/project_descriptions/README.md#data605-big-data-systems)
   - [MSML610 projects](https://github.com/gpsaggese/gpsaggese.github.io/blob/master/class_project/project_descriptions/README.md#msml610-advanced-machine-learning)
2. There are more packages that would be interesting to study, listed in
   [all_projects.md](https://github.com/gpsaggese/gpsaggese.github.io/blob/master/class_project/all_projects.md)
   - These are available only on request, since a project description needs to be
     written first
3. Improve an old tutorial or project:
   - You can pick up work from a previous student or group of students and build on
     top of it
   - Use this option if you want to work on a specific technology that another
     student already picked
   - You need to agree on the project scope with GP

# Sign Up

- Fill out this
  [form](https://docs.google.com/forms/d/1TPCt7UFnTOEICltrPU3sIu9RoCbILR32zHbZNzRi9jw/edit)

- You can select 3 projects you are interested in and then we'll assign randomly one
  to you out of the 3 you liked
  - Make sure to pick something you are ok with and don't change your mind once we
    assign you one of those 3

- To select a project you need to use its description
  1. For a small research project use a link selected from
     https://github.com/gpsaggese/gpsaggese.github.io/blob/master/research/ideas/README.md
     - E.g., https://github.com/gpsaggese/gpsaggese.github.io/blob/master/research/ideas/draft.AI_Architecture_Decision_Support.md
       for the project "draft.AI_Architecture_Decision_Support.md"
  2. For a tutorial use a link selected from the lists
     [DATA605](https://github.com/gpsaggese/gpsaggese.github.io/blob/master/class_project/project_descriptions/README.md#data605-big-data-systems)
     [MSML610](https://github.com/gpsaggese/gpsaggese.github.io/blob/master/class_project/project_descriptions/README.md#msml610-advanced-machine-learning)
      - E.g., enter the link
        https://github.com/gpsaggese/gpsaggese.github.io/blob/master/class_project/project_descriptions/MSML610/Hyperopt_Project_Description.md
        for "Hyperopt"
