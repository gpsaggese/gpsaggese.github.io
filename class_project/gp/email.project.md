# Small Research Projects

- The project is _"Research a question"_
  - Implement a research project based on instructions
  - Create Jupyter notebooks to demo your project
  - Commit code to GitHub and contribute to open-source repo
  - Write a blog entry / paper for you project
  - Present your project in a video

- You can pick a new project or continue a research idea that other students already
  started
  - It is important to learn how to build on top of other people's work (only 1% of
    the times you can start something totally new in your job, while 99% is about
    getting something built by somebody else and improve it / add to it)

# Tutorials "Learn X in 60 minutes" / "Build X with Y"

- The project consists in _"Learning and building with a given technology"_
  - Choose $X$ and $Y$ from a list
  - Study and describe technology $Y$
  - Implement use case $X$ using technology $Y$
  - Commit code to GitHub and contribute to open-source repo
  - Write a blog entry for you project
  - Present your project in a video
