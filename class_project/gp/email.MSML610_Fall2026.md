## Suggestions / advices for the project

**Date:** Nov 10, 2026, 10:14 AM  
**Author:** Giacinto Paolo Saggese

Hello team,

Good progress on the projects. Summarizing some answers I gave to several teams

1) Make sure you have created a "master issue" for your project following the conventions UmdClassXYZ_...

2) Do one PR with the skeleton of the project so that the template is checked in

3) Start making progress by creating PRs. You can make as many PRs as you want, using PRs as a way to do checkpoints and get feedback from us.

Personally 2-3 PRs is enough, since most of the feedback comes at the end when all the pieces are in place.

4) If you have a research project , you can create a gdoc to document the research following

`./helpers_root/docs/planning/all.document_research.how_to_guide.md`

And using this as an examples

https://docs.google.com/document/d/19KGM-1a9U5E7CrE4ltljYz7IVtMfNuRzrqgGkkuXUSQ/edit

5) Save the results in the dir https://drive.google.com/drive/folders/1NQB-LgY6Kn8Pw5Hbnp_1yCzN9HgoDIXe

6) Do not add binary files, training data, monster files to the repo. Better to save them in your dir on a Gdrive above and read it from there

7) For the implementation, if you use AI (which is a bit of a rhetorical question), I suggest following the workflow from

`./docs/planning/all.document_research.how_to_guide.md`

So at the least not everybody is reinventing the wheel ;-)

I hope you are enjoying building as much as I am enjoying seeing you build cool stuff.

Have fun and good luck.
