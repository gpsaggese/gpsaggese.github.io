Please thoroughly check and confirm the following before raising a pull request (PR) for review:

**1. Branch management**

- Only create a new branch after your previous branch has been successfully merged. This prevents conflicts and unnecessary complexity.

**2. Docker & script templates**

- Most PRs currently include both Docker templates (Causify style and DATA605 style). Please choose and use only one template — **DATA605 style is recommended** — and remove the unnecessary files.
- Clearly add your dependencies and make necessary changes within the selected Docker files.
- Some PRs don't have the updated template files added to their project directory. Make sure you do so.

**3. File management**

- Work exclusively within your designated directory.
- Avoid moving, deleting, or modifying files that may affect other team members' directories or the shared environment.
- Track and commit **only essential files** necessary for your project. Exclude any unnecessary files from your commits.

Make sure to follow this checklist before raising a PR and asking for a review.

**TIP:** Run `git status` to identify modified files clearly and selectively commit only those complying with the above checklist.
