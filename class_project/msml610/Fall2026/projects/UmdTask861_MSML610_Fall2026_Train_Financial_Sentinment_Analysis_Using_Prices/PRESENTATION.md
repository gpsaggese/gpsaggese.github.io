# Student presentation and final submission

This is a recording guide, not a completed video or evidence of student review.
The course requires a **10–20 minute student presentation**. Aim for 12–15 minutes.
Use your own words and demonstrate the executed notebooks; explain the limitations
as carefully as the successful output. Do not describe assisted coding as an
independent human attribution review.

| Time | On screen | Explain |
| --- | --- | --- |
| 0:00–0:30 | Project title | Your name and UID, course, research title, Python tools and difficulty. Enter UID only in the intended course submission, not the public repo. |
| 0:30–1:00 | Course PR files | Issue 861, required branch/directory naming, Python utilities and paired notebooks. |
| 1:00–2:00 | Docker and Jupyter | Build success, container command, localhost Jupyter and authenticated URL. Hide token before recording. |
| 2:00–4:00 | API notebook | Run every cell; source dates versus receipt times, numerical feature packet, units and missing-outcome rejection. |
| 4:00–7:00 | Example refit | Run every cell; training-only transformations, ridge alpha, 91/87 split, independent solution and prediction agreement. |
| 7:00–9:00 | BERT comparison | Nine models, 272/154 rows, completed fine-tuning versus replaying a saved report; mixed outcomes. |
| 9:00–11:00 | Strategy and attribution | B minus C, assumed costs, drawdown resolution, 26 detected moves, missing independent gold. |
| 11:00–13:00 | README and sources | How another reader runs the package, what is still unavailable, and the next defensible experiment. |

Before final submission: complete independent attribution review, recover or
replace missing original inputs under a separately registered protocol, verify
the course PR's reviewers, record your own video, and upload it to the
[official course Drive folder](https://drive.google.com/drive/folders/1QLtgPCAS0mqE9cr1hE3UVoIbzakCNtaC).
Link the uploaded video in the PR. Reviewer acceptance and the video are not
completed by creating the checkpoint PR.
