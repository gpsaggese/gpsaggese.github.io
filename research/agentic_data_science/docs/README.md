# Docs

- The docs of the Agentic Data Science project: what we build, in which order,
  what is done, and why
- Start with `how_we_work.md`, then `plan.md`
- The code has its own READMEs:
  - `../schema_agent/README.md`
  - `../bakeoff/README.md`

## Structure of the Dir

- There are no subdirs: all the docs sit at the top level, grouped by cluster

## Description of Files

| File             | Description                                       | Cluster    |
| :--------------- | :------------------------------------------------ | :--------- |
| `how_we_work.md` | How the team works on the project                 | Onboarding |
| `plan.md`        | What to build and in which order                  | Plans      |
| `progress.md`    | What is done, what we learned, and what is next   | Plans      |
| `decisions.md`   | Why it is built this way                          | Specs      |
