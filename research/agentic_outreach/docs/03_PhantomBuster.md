## Sales Navigator Search Export
Log in to [https://phantombuster.com/](https://phantombuster.com/)

### Get an SN Search
Create a search with SalesNavigator

Give a symbolic name to each one so it's easy to track what is what through the
code and the Gdocs

E.g., let's process the search called "crypto_miners_1"

Go to the dashboard of PB

<img

Rename the Phantom

<img
src="ai_outreach_process_figs/image44.png"

Copy/paste the SN search

<img
src="ai_outreach_process_figs/image40.png"
style="width:6.5in;height:4.04167in" />

Connect to LinkedIn so that PB can use your profile (you need to install a
Chrome extension to extract the API key from LinkedIn)

<img
src="ai_outreach_process_figs/image14.png"
style="width:6.5in;height:2.30556in" />

Accept defaults

<img
src="ai_outreach_process_figs/image9.png"
style="width:6.5in;height:3.04167in" />

Select repeatedly and pick a frequency that is large but doesn't exceed the
maximum limit from LinkedIn

<img
src="ai_outreach_process_figs/image33.png"
style="width:6.5in;height:2.51389in" />

Launch the scraper

<img
src="ai_outreach_process_figs/image47.png"
style="width:6.5in;height:1.51389in" />

Exporting values of a search is very fast. In a few minutes you should have the
results

<img
src="ai_outreach_process_figs/image32.png"
style="width:6.5in;height:2.13889in" />

Download results and save them in a Google sheet called like your search. It's
best to be organized and save them in a central directory.

Rename the tab as Search Export

<img
src="ai_outreach_process_figs/image17.png"
style="width:6.5in;height:3.34722in" />

Clean up the Google Sheet by removing all incorrect matches. Extracting the
profile info takes a long time so you want to remove anything that is a waste of
time.
