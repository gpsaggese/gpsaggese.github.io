# Design: Pipeline

## Goal

- Run the three stages of the pipeline on one papers CSV and one output dir, and run
  the resolver as a separate executable that reads and writes CSV
  ([`D26`](/research/Estimate_academic_paper_quality/docs/03-decisions.md#d26-the-resolver-is-a-separate-executable-that-reads-and-writes-csv))
  - Parse and check the CLI flags, select the stages, call the other components
  - Loop on the papers, and turn a failure of one paper into an `Issue`, so the run
    goes on (PRD
    [`R5`](/research/Estimate_academic_paper_quality/docs/01-prd.md#r5-unresolved-or-ambiguous-line),
    [`R10`](/research/Estimate_academic_paper_quality/docs/01-prd.md#r10-failed-download-or-conversion))
  - Skip the work that a previous run already did
    ([`R11`](/research/Estimate_academic_paper_quality/docs/01-prd.md#r11-rerun-skips-converted-papers),
    [`R17`](/research/Estimate_academic_paper_quality/docs/01-prd.md#r17-rerun-skips-extraction))
- Where it fits: user -> `pipeline` -> `resolver`, `fetcher`, `extractor`, `rater`,
  `report`
- Overview:
  [`research/Estimate_academic_paper_quality/docs/02-design.architecture.md`](/research/Estimate_academic_paper_quality/docs/02-design.architecture.md)
- Decisions:
  [`research/Estimate_academic_paper_quality/docs/03-decisions.md`](/research/Estimate_academic_paper_quality/docs/03-decisions.md)

## One Request End to End

- `_main()`:
  - Checks at the boundary that `--input` (the papers CSV) exists, and that
    `--resolve_issues` exists if it is set, then creates `papers/` and `state/` under
    `--output_dir`
  - Without `--resolve_issues`, uses the issues CSV next to the papers CSV
    (`papers.csv` gives `papers.issues.csv`) if it exists, and logs a warning if not
  - Sets the cache dir of [`hcache_simple`](/helpers_root/helpers/hcache_simple.py)
    to `<output_dir>/state/cache/` and applies `--cache_mode`
  - Builds `PipelineConfig`, reads the papers of the papers CSV with `read_papers()`,
    then runs the selected stages in this order: `download`, `extract`, `report`
  - Passes the papers to each stage; the output of a stage that is not selected is
    read from `<output_dir>`
    ([`D18`](/research/Estimate_academic_paper_quality/docs/03-decisions.md#d18-all-the-state-lives-in-the-output-dir))
- `resolve_papers._main()` runs the resolver and is not a stage of
  `estimate_paper_quality.py`:
  - Reads the column `input` with `read_input_lines()`, which calls
    `epq_report.read_input_csv()` and `epq_resolver.parse_line()`
  - `run_resolve_csv(input_csv, papers_csv, issues_csv, sources)` calls
    `epq_resolver.resolve_line()` for each line inside a `try` (the catch of D21, so a
    failed lookup is an `unresolved` issue), then `finalize_papers()`
  - Writes the papers CSV and the issues CSV with `epq_report`
  - With `--dry_run`, only logs the kind of each row
- `run_download(config, papers)`:
  - For each paper: skips it if `epq_fetcher.is_fetched()` is true
    ([`R11`](/research/Estimate_academic_paper_quality/docs/01-prd.md#r11-rerun-skips-converted-papers))
  - Else calls `epq_fetcher.fetch_paper()` and turns a failed `FetchResult` into an
    `Issue` with status `no_download_link`, `download_failed`, or `conversion_failed`
  - Writes `state/issues.download.json`
- `run_extract(config, papers)`, for each paper:
  - Skips it if it has no markdown (the download issue already says why)
  - Skips it if its features file exists and `--force_extract` is not set
    ([`R17`](/research/Estimate_academic_paper_quality/docs/01-prd.md#r17-rerun-skips-extraction))
  - Reads the markdown and the text of each PDF page with `epq_fetcher`
  - Calls `epq_extractor.extract_features()` with an injected LLM function
  - Calls `epq_bib_sources.get_citation_count()`, with `REFRESH_CACHE` when
    `--force_extract` is set, so the count is fresh
  - Calls `epq_rater.rate_paper()` with the page count, the affiliations, the
    citation count, the year, and `config.today`
  - Builds the Recency feature from the year of the record, with the name of the
    source as evidence
  - Writes `papers/<BASE>.features.json` with `epq_report`
  - Logs the LLM cost of the paper and, at the end, the total
- `run_report(config, papers)`:
  - Reads the features files, the issues CSV of the resolver, and the issues of the
    other stages
  - Writes `references.md`, `report.csv`, and `issues.csv`
- Error handling
  ([`D21`](/research/Estimate_academic_paper_quality/docs/03-decisions.md#d21-the-loop-of-each-stage-catches-errors-per-paper)):
  - The inner modules assert with `hdbg.dassert_*` and raise
  - The loop of each stage catches `Exception` per paper and records an `Issue` with
    the last line of the message as the reason
  - An error outside the loop (e.g., a bad flag, a full disk) stops the run

## Configuration, Interfaces, and Known Limits

- Configuration:
  ```python
  @dataclasses.dataclass(frozen=True)
  class PipelineConfig:
      # Papers CSV that `resolve_papers.py` wrote.
      papers_file: str
      # Issues CSV that `resolve_papers.py` wrote, "" if there is none.
      resolve_issues_file: str
      output_dir: str
      # LLM of `extract`, "" for the default model of `helpers.hllm`.
      model: str
      force_extract: bool
      # Max chars of markdown sent to the LLM (D13).
      max_chars: int
      # Date used to annualize the citations, injected for tests.
      today: datetime.date
      # `REFRESH_CACHE`, `DISABLE_CACHE`, `HIT_CACHE_OR_ABORT`, or "".
      cache_mode: str
      # Key of Semantic Scholar, "" for the shared pool.
      s2_api_key: str
  ```
- Interfaces: CLI flags

  | Flag                                                            | Default      | Meaning                                                                                                                                                                                 |
  | :-------------------------------------------------------------- | :----------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
  | `--input`                                                       | required     | Papers CSV that `resolve_papers.py` wrote ([`D26`](/research/Estimate_academic_paper_quality/docs/03-decisions.md#d26-the-resolver-is-a-separate-executable-that-reads-and-writes-csv)) |
  | `--resolve_issues`                                              | `""`         | Issues CSV that `resolve_papers.py` wrote; empty is the papers CSV with `.issues.csv`, if it exists                                                                                     |
  | `--output_dir`                                                  | required     | Dir of all outputs and state ([`D10`](/research/Estimate_academic_paper_quality/docs/03-decisions.md#d10-the-user-gives-the-output-dir))                                                |
  | `--model`                                                       | `""`         | LLM for `extract`                                                                                                                                                                       |
  | `--force_extract`                                               | off          | Extract again papers with a features file                                                                                                                                               |
  | `--max_chars`                                                   | `300000`     | Cap on the markdown sent to the LLM                                                                                                                                                     |
  | `--cache_mode`                                                  | `""`         | `REFRESH_CACHE` refetches metadata and citations                                                                                                                                        |
  | `--action`, `--skip_action`, `--clear_actions`, `--all_actions` | all 3 stages | Stage selection                                                                                                                                                                         |
  | `-v`                                                            | `INFO`       | Log level                                                                                                                                                                               |

- Known limits:
  - Sequential: one paper at a time
  - A rerun must use the same `--output_dir`
  - A paper removed from the input list keeps its files in `papers/`, but leaves the
    report

## Deliberately Not Built

- A config file: the flags are few
- Parallel stages, retries of a failed paper in the same run: a rerun retries it
