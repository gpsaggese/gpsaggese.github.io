# Design: Report

## Goal

- Write and read every file that the pipeline keeps in `<output_dir>`
  - `references.md`: the normalized list of references (PRD
    [`R2`](/research/Estimate_academic_paper_quality/docs/01-prd.md#r2-reference-format),
    [`R7`](/research/Estimate_academic_paper_quality/docs/01-prd.md#r7-reverse-chronological-order))
  - `report.csv`: one row per paper with a features file
    ([`R18`](/research/Estimate_academic_paper_quality/docs/01-prd.md#r18-report-csv))
  - `issues.csv`: the unresolved lines and the failed papers, with the reason
    ([`R19`](/research/Estimate_academic_paper_quality/docs/01-prd.md#r19-issues-csv))
  - `papers/<BASE>.features.json`: the features, the evidence, the facts, and the
    rating of one paper
    ([`R20`](/research/Estimate_academic_paper_quality/docs/01-prd.md#r20-features-file)),
    also the rerun cache of `extract`
    ([`R17`](/research/Estimate_academic_paper_quality/docs/01-prd.md#r17-rerun-skips-extraction))
  - `state/issues.<stage>.json`: the issues of the stages `download` and `extract`,
    so that each stage can run alone
  - The input CSV, the papers CSV, and the issues CSV of `resolve_papers.py`
    ([`D26`](/research/Estimate_academic_paper_quality/docs/03-decisions.md#d26-the-resolver-is-a-separate-executable-that-reads-and-writes-csv))
- Where it fits: `pipeline` -> `report` -> files
- Overview:
  [`research/Estimate_academic_paper_quality/docs/02-design.architecture.md`](/research/Estimate_academic_paper_quality/docs/02-design.architecture.md)
- Decisions:
  [`research/Estimate_academic_paper_quality/docs/03-decisions.md`](/research/Estimate_academic_paper_quality/docs/03-decisions.md)
  - The features file is JSON, read back by the pipeline
    ([`D14`](/research/Estimate_academic_paper_quality/docs/03-decisions.md#d14-the-features-file-is-json-and-is-the-rerun-cache-of-extract))
  - `report.csv` has one row per paper with a features file; the other papers are in
    `issues.csv`
    ([`D19`](/research/Estimate_academic_paper_quality/docs/03-decisions.md#d19-reportcsv-has-a-row-only-for-a-paper-with-a-features-file))
  - The normalized list also goes to `references.md`
    ([`D20`](/research/Estimate_academic_paper_quality/docs/03-decisions.md#d20-the-normalized-list-also-goes-to-referencesmd))

## One Request End to End

- `run_report()` of `pipeline` calls, in order:
  - `read_papers_csv(papers_csv)`: the papers, already in
    [`R7`](/research/Estimate_academic_paper_quality/docs/01-prd.md#r7-reverse-chronological-order)
    order
  - `read_issues_csv(issues_csv)`: the issues of `resolve_papers.py`
  - `read_issues(path)`: the issues of `download` and `extract`
  - `read_features_file()` for each paper that has one
  - `write_references(path, papers)`: one bullet per resolved paper, e.g.,
    ```markdown
    - 2020, Cohen et al., "Lazy Prices" (https://doi.org/<DOI> ???)
    ```
  - `write_report(path, build_report_rows(papers, features))`
  - `write_issues_csv(path, issues)`, by stage, then by line number
- Columns of `report.csv`
  ([`R18`](/research/Estimate_academic_paper_quality/docs/01-prd.md#r18-report-csv)):

  | Column               | Content                                                                                               |
  | :------------------- | :---------------------------------------------------------------------------------------------------- |
  | `reference`          | The reference of [`R2`](/research/Estimate_academic_paper_quality/docs/01-prd.md#r2-reference-format) |
  | `paper_quality`      | Rating 1 to 5, or `unknown`                                                                           |
  | `performance`        | Free text, or `unknown`                                                                               |
  | `recency`            | Publication year                                                                                      |
  | `asset_class`        | Free text, or `unknown`                                                                               |
  | `theoretical_domain` | Free text, or `unknown`                                                                               |
  | `mechanism`          | Free text, or `unknown`                                                                               |
  | `page_length_score`  | 1 to 5, or `unknown`                                                                                  |
  | `affiliation_score`  | 1 to 5, or `unknown`                                                                                  |
  | `citations_score`    | 1 to 5, or `unknown`                                                                                  |
  | `base_name`          | `<BASE>`, to open the PDF and the features file                                                       |

- Columns of the papers CSV of `resolve_papers.py`: `reference`, `year`, `authors`,
  `title`, `doi`, `arxiv_id`, `s2_paper_id`, `source`, `base_name`, `download_inputs`,
  `line_nos`, `key`, `aliases`
  - A list (e.g., `authors`) is one cell with the items joined by `|`
  - The input CSV has the column `input` and the issues CSV has the columns of
    `issues.csv`, below
- Columns of `issues.csv`
  ([`R19`](/research/Estimate_academic_paper_quality/docs/01-prd.md#r19-issues-csv)):
  `line_no`, `input`, `base_name`, `stage`, `status`, `reason`, `candidates` (joined
  by `|`)
  - `status` is one of `unresolved`, `ambiguous`, `no_download_link`,
    `download_failed`, `conversion_failed`, `extraction_failed`
- Shape of a features file (values are illustrative):
  ```json
  {
    "schema_version": 1,
    "base_name": "2020.Cohen_et_al.Lazy_Prices",
    "features": {
      "performance": {
        "value": "Sharpe 1.4, out of sample, 2005 to 2020",
        "evidence": {"quote": "...", "location": "Table 4, p. 21", "verified": true}
      },
      "recency": {
        "value": "2020",
        "evidence": {"quote": "2020", "location": "Semantic Scholar", "verified": true}
      }
    },
    "facts": {"sharpe_ratios": [], "sample_periods": [], "...": "..."},
    "quality": {
      "rating": 4,
      "citations": {
        "value": "512 (Semantic Scholar, 2026-10-28)", "score": 4, "evidence": null
      },
      "...": "..."
    },
    "provenance": {"model": "...", "prompt_sha1": "...", "cost_usd": 0.04}
  }
  ```

## Configuration, Interfaces, and Known Limits

- Configuration: `_SCHEMA_VERSION = 1` for the JSON files; CSV in UTF-8, with
  `csv.QUOTE_MINIMAL`, and a BOM at the start of a file that is read is skipped
- Interfaces:
  ```python
  def read_input_csv(path: str) -> List[Tuple[int, str]]: ...
  def write_papers_csv(path: str, papers: List[epqtypes.Paper]) -> None: ...
  def read_papers_csv(path: str) -> List[epqtypes.Paper]: ...
  def read_issues_csv(path: str) -> List[epqtypes.Issue]: ...
  def write_features_file(path: str, features: epqtypes.PaperFeatures) -> None: ...
  def read_features_file(path: str) -> epqtypes.PaperFeatures: ...
  def build_report_rows(
      papers: List[epqtypes.Paper],
      features: Dict[str, epqtypes.PaperFeatures],
  ) -> List[Dict[str, str]]: ...
  def write_report(path: str, rows: List[Dict[str, str]]) -> None: ...
  def write_issues_csv(path: str, issues: List[epqtypes.Issue]) -> None: ...
  def write_references(path: str, papers: List[epqtypes.Paper]) -> None: ...
  ```
- Known limits:
  - A features file with an old `schema_version` fails to read: `pipeline` records an
    issue that asks for `--force_extract`
  - `report.csv` shows the values only: the evidence is in the features file
  - A CSV file has no schema version: a file with a missing column fails to read
  - An item of a list cell must not hold `|`

## Deliberately Not Built

- An HTML or spreadsheet view: the user sorts the CSV
  ([PRD Non-Goals](/research/Estimate_academic_paper_quality/docs/01-prd.md#non-goals))
- A merge of user edits: the CSV is written again on each run
