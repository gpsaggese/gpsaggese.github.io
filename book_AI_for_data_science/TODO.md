# Phases of Building a Machine Learning Model

1. **Problem Definition** — Translate a business or research question into an
   ML-solvable problem; define success metrics and constraints.
2. **Data Collection** — Gather data from databases, APIs, logs, sensors, or
   third-party sources.
3. **Data Cleaning & Preprocessing** — Handle missing values, duplicates,
   outliers, and inconsistent formatting.
4. **Exploratory Data Analysis (EDA)** — Visualize distributions, correlations,
   and patterns; form hypotheses about feature importance.
5. **Feature Engineering & Selection** — Create new variables, encode categorical
   data, scale/normalize features, reduce dimensionality.
6. **Data Splitting** — Divide data into training, validation, and test sets (or
   cross-validation folds).
7. **Model Selection & Training** — Choose candidate algorithms, train on the
   training set, tune hyperparameters using validation data.
8. **Model Evaluation** — Assess performance on the held-out test set using
   appropriate metrics (accuracy, F1, RMSE, AUC, etc.).
9. **Deployment** — Package and integrate the model into production systems
   (APIs, batch jobs, embedded apps).
10. **Monitoring & Maintenance** — Track performance over time, watch for
    data/concept drift, retrain as needed.
