### Tutorials & Explanations

- **[DPO Explained from First Principles](https://medium.com/@thekzgroupllc/direct-preference-optimization-dpo-explained-from-first-principles-ba6954ae1cdd)** — Medium article by Zaina Haider covering core concepts with clear intuition

- **[Direct Preference Optimization (DPO) — Hugging Face](https://huggingface.co/learn/smol-course/unit2/2)** — Official Hugging Face course introduction to DPO with code examples
- **[Direct Preference Optimization (DPO) on Medium](https://medium.com/@joaolages/direct-preference-optimization-dpo-622fc1f18707)** — João Lages' detailed breakdown

### Key Concepts Covered
- Reparameterizing the RLHF objective via closed form
- Implicit reward from policy log-probabilities
- DPO loss as supervised classification without reward model
- Advantages over traditional RLHF (no RL, no reward model, fewer hyperparameters)

## 2. Chain-of-Verification (CoVe)

### Tutorials & Explanations

- **[Chain-of-Verification (CoVe): Reduce LLM Hallucinations](https://learnprompting.org/docs/advanced/self_criticism/chain_of_verification)** — Learn Prompting guide with practical examples
- **[CoVe: How to Reduce LLM Hallucinations](https://brics-econ.org/chain-of-verification-cove-how-to-reduce-llm-hallucinations)** — Conceptual overview of the method
- **[Advanced Stack: CoVe Implementation Guide](https://advanced-stack.com/archives/resources/how-to-reduce-hallucinations-using-chain-of-verification-cov-in-large-language-models.html)** — Technical implementation overview
- **[LangChain Implementation of CoVe](https://medium.com/@james.li/a-langchain-implementation-of-chain-of-verification-cove-to-reduce-hallucination-0a8fa2929b2a)** — James Li's practical code walkthrough with LangChain
- **[Chain-Of-Verification Reduces Hallucination in LLMs](https://cobusgreyling.medium.com/chain-of-verification-reduces-hallucination-in-llms-20af5ea67672)** — Cobus Greyling's intuitive explanation
- **[Original Paper on OpenReview](https://openreview.net/forum?id=VP20ZB6DHL)** — Community discussion and peer review
- **[Official Paper (arXiv)](https://arxiv.org/pdf/2309.11495)** — Dhuliawala et al., 2023

### Key Concepts Covered
- Factored vs. joint verification strategies
- Escaping anchoring bias through decomposition
- Four-step algorithm: draft → plan → execute → revise
- Reduces hallucinations without external oracle
- Model-agnostic (works with any LLM via API)

## 3. Iterative Reasoning Preference Optimization (IRPO)

### Tutorials & Explanations

- **[Iterative Reasoning Preference Optimization — DEV Community](https://dev.to/mikeyoung44/iterative-reasoning-preference-optimization-5dic)** — Accessible overview with step-by-step breakdown
- **[NeurIPS 2024 Slides](https://neurips.cc/media/neurips-2024/Slides/96659_nZhhoGi.pdf)** — Official presentation slides from the conference
- **[AIModels.fyi Paper Details](https://www.aimodels.fyi/papers/arxiv/iterative-reasoning-preference-optimization)** — Structured summary of the research

### Implementation & Integration

- **[GitHub Issue: IRPO Implementation in TRL](https://github.com/huggingface/trl/issues/1611)** — Discussion of adding IRPO support to Hugging Face TRL library
- **[ArXiv Paper](https://arxiv.org/abs/2404.19733)** — Pang et al., 2024 (original reference in lesson)

### Key Concepts Covered
- Self-generated correctness-based preference pairs
- DPO + NLL (negative log-likelihood) anchor term
- Iterative bootstrapping: model generates its own curriculum
- Results: GSM8K accuracy from 55.6% → 81.6% on Llama-2-70B-Chat
- No external training data required beyond unlabeled prompts

- **[RewardBench: Evaluating Reward Models for Language Modeling](https://arxiv.org/pdf/2403.13787)** — Standardized benchmark for reward model evaluation
- **[M-RewardBench: Multilingual Evaluation](https://arxiv.org/pdf/2410.15522)** — Extension to multilingual settings

### Key Concepts Covered
- Bradley-Terry model of preferences
- Preference pairs: (prompt, chosen, rejected)
- Reward model as binary classifier learning preference patterns
- Training setup using SequenceClassification transformers

## 5. Open-Source Libraries & Implementations

### Hugging Face TRL (Transformers Reinforcement Learning)

- **[TRL Documentation](https://huggingface.co/docs/trl/index)** — Full documentation and API reference
- **[TRL GitHub Repository](https://github.com/huggingface/trl)** — Source code and examples
- **[DPOTrainer Implementation](https://github.com/huggingface/trl/blob/main/trl/trainer/dpo_trainer.py)** — Direct implementation of DPO algorithm
- **[Online DPO Trainer Docs](https://github.com/huggingface/trl/blob/main/docs/source/online_dpo_trainer.md)** — Extension for online (prompt-only) DPO

#### Key Features
- Pre-built trainers: DPOTrainer, RewardTrainer, SFTTrainer
- Integrated with 🤗 transformers models
- Support for vision-language models (Idefics2, LLaVA, PaliGemma)
- Both Python API and CLI interfaces
- Supports both offline and online DPO variants
