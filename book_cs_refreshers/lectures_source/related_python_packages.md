## Cluster 3. Nash Equilibrium Computation

### Gambit

- **Description**: Comprehensive game theory library for n-player games and complex
  game structures
- **GitHub**: https://github.com/gambitproject/gambit
- **Docs**: https://www.gambit-project.org
- **Stars**: 594
- **Status**: active
- **Category**: Game Theory
- **Lessons**: 95
- **Features**:
  - Handles n-player games and complex game structures
  - Solves for various equilibrium types
  - Provides the `pygambit` Python API
- **Alternatives**:
  - Nashpy

### Nashpy

- **Description**: Most popular dedicated game theory library for computing Nash
  equilibria in 2-player games
- **GitHub**: https://github.com/drvinceknight/Nashpy
- **Docs**: https://nashpy.readthedocs.io
- **Stars**: 382
- **Status**: active
- **Category**: Game Theory
- **Lessons**: 95
- **Features**:
  - Computes Nash equilibria of 2-player normal form games
  - Implements support enumeration, vertex enumeration, and Lemke-Howson
  - Simulates learning dynamics such as fictitious play and replicator dynamics
- **Alternatives**:
  - Gambit
