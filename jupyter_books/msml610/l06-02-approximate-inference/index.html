Approximate Inference in Bayesian Networks

  • This notebook teaches how to estimate posteriors P(X∣e)P(X \mid \mathbf{e})P(X∣e) by sampling, when exact inference is too expensive or impossible
  • Concepts are built on the Garden Wold examples with variables to run the query P(Rain∣Sprinkler=T)P(Rain \mid Sprinkler{=}T)P(Rain∣Sprinkler=T)
  • The flow is:
    • Turn uniform randomness into samples (inverse transform)
    • Sample a whole network (prior sampling)
    • Watch estimates converge (1/N1/\sqrt{N}1/N​)
    • Condition on evidence by rejection
    • Rescue rare evidence with importance weights
    • Walk the state space with MCMC (mixing, Gibbs, Metropolis-Hastings)
  • The exact posteriors from pgmpy are reused throughout as the ground-truth reference that every estimate is compared against
