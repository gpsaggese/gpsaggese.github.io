## Cluster 1. Automated Theorem Proving, SAT/SMT, and Satisfiability

### z3-solver

- **Description**: SMT solver for first-order theories: satisfiability, validity,
  proof by contradiction, and consistency checking
- **GitHub**: https://github.com/Z3Prover/z3
- **Docs**: https://github.com/Z3Prover/z3
- **Stars**: 12,896
- **Status**: active
- **Category**: Knowledge Representation & Logic
- **Lessons**: 03.2, 03.3
- **Features**:
  - Solves satisfiability over Boolean, integer, real, and bit-vector theories
  - Returns models and unsat cores
  - Provides a Python API with the `Solver` class
- **Alternatives**:
  - aima-python
  - PySAT

### aima-python

- **Description**: Companion code for Russell and Norvig's AIMA, cited in this
  lecture: KB agents, propositional and FOL inference, forward and backward chaining
- **GitHub**: https://github.com/aimacode/aima-python
- **Docs**: https://github.com/aimacode/aima-python
- **Stars**: 8,871
- **Status**: active
- **Category**: Knowledge Representation & Logic
- **Lessons**: 03.1, 03.2
- **Features**:
  - Implements the algorithms of the AIMA textbook
  - Includes knowledge base agents and propositional and FOL inference
  - Provides forward and backward chaining
  - Ships Jupyter notebooks that explain the algorithms
- **Alternatives**:
  - z3-solver
  - PySAT

### PySAT

- **Description**: SAT solver toolkit with DPLL and CDCL backends for satisfiability

- **GitHub**: https://github.com/pysathq/pysat
- **Docs**: https://pysathq.github.io
- **Stars**: 466
- **Status**: active
- **Category**: Knowledge Representation & Logic
- **Lessons**: 03.2, 03.3
- **Features**:

  - Supports incremental solving with assumptions
  - Provides cardinality encodings and MaxSAT solving
- **Alternatives**:
  - z3-solver
  - aima-python
